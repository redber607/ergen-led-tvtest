# Ergen Led Tv Elektronik Web Projesi

Bu proje **Antigravity** tarafından oluşturulmuştur.

**Son Güncelleme:** 2026-02-01
**Durum:** Faz 1 Tamamlandı (Tasarım ve Kodlama)

## 📂 Proje İçeriği
- **index.html**: Ana sayfa (Arama ve Vitrin)
- **products.html**: Ürünler (Kategori ve Arama Filtreli)
- **about.html**: Hakkımızda (Tarihçe)
- **contact.html**: İletişim (Form ve Banka Bilgileri)

- **script.js**: Mobil menü, arama motoru, çerez politikası mantığı
